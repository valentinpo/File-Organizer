# 📁 File-Organizer

Кроссплатформенный GUI-органайзер файлов на Python. Сортировка по расширениям и датам, тёмная/светлая тема, безопасный тестовый режим, логирование. Без зависимостей.

## ⬇️ Скачать

Готовая сборка доступна в [Releases](https://github.com/valentinpo/File-Organizer/releases):

- **`FileOrganizer.exe`** — версия **v1.5.0**

> ⚠️ Исходный код появится в этом репозитории позже. На данный момент репозиторий оформлен как релиз-центр с готовым `.exe`.

## ✨ Возможности

- 📁 **Сортировка файлов** по расширениям и датам
- 🌓 **Тёмная / светлая тема** интерфейса
- 🧪 **Тестовый режим** — безопасная «репетиция» без реального перемещения файлов
- 📜 **Логирование** всех операций
- ⚡ **Без зависимостей** — работает на стандартной библиотеке Python

## ✅ Системные требования

- Windows, macOS или Linux
- Python 3.x (для запуска из исходников)
